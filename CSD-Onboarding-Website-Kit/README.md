# CSD Onboarding Website Kit

This kit contains the starter content and prompts for building a one-scroll, student-centred CSD onboarding website in Google AI Studio.

## Contents
- `02_Content/csd-website-data.json` — website content and structured diagram stages.
- `02_Content/00_STARTER_PROMPT.txt` — short folder-reference prompt.
- `02_Content/01_MASTER_BUILD_PROMPT.txt` — full build prompt.
- `02_Content/02_MAPS_LATER_PROMPT.txt` — prompt for integrating source maps later.
- `02_Content/03_REFINEMENT_PROMPT.txt` — visual and interaction refinement.
- `02_Content/04_CONTENT_AUDIT_PROMPT.txt` — accuracy and functionality audit.
- `05_Technical-Guidelines/DESIGN_GUIDELINES.md` — visual, motion, content and accessibility rules.
- `05_Technical-Guidelines/GOOGLE_AI_STUDIO_SETUP.md` — step-by-step workflow.
- `01_Research/ADD_SOURCE_FILES_HERE.txt` — reminder to add original research files.
- `03_Visual-Assets/ADD_VISUAL_ASSETS_HERE.txt` — reminder to add images/icons/exports.
- `04_Design-References/ADD_REFERENCES_HERE.txt` — reminder to add visual references.

## Map note
You can build the first version before the maps are ready. The dataset includes process/journey stages and an actor list. The actor map edges are intentionally empty until the original map or research verifies exact relationships. No Alumni in the actor map or stakeholder network.

## Source integrity
This package is a starter. Review all labels and process details against your original research before publishing. Suggested scenario responses are not official policy.
